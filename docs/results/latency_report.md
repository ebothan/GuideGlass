# Latency report (gate G3)

Generated by `core/src/main/kotlin/org/guideglass/core/sim/Demo.kt` over 300 scenario runs (10 obstacle scenarios x 30 seeds, 36660 frames).

**Read this first.** Stages 1-5 and the Bluetooth audio stage cannot be measured without the glasses and a phone.
In this report they are *drawn* from distributions chosen to match the assumed budget in
`docs/00-problem-constraints-goals.md` section 7, so their pass marks only confirm the arithmetic. What is
measured here is (a) the decision core's own compute time on this desktop JVM [M, desktop proxy, not a phone],
(b) the time cues wait in the arbiter behind other cues, and (c) how the prediction to the ear behaves end to end.
